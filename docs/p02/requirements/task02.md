# Практическая работа № 2. Задание 2. Вариант 3

Используя алгоритм Кнута–Морриса–Пратта, найти индекс последнего вхождения
образца в текст.

В отчёте требуется:

- разобрать алгоритм поиска на примере;
- подсчитать число сравнений при успешном нахождении первого вхождения и при
  безуспешном поиске;
- определить функции, их предусловия и постусловия;
- проверить успешный и неуспешный поиск на небольших и больших данных;
- оценить практическую сложность в зависимости от длины текста и образца и
  представить результаты в таблице;
- сформулировать вывод по результатам работы.
